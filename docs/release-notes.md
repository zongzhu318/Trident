Trident 0.4.0 首次接入 Sparkle 更新。

- 在 macOS「Trident」菜单中选择「检查更新…」或开启「自动检查更新」。
- 更新包和更新清单均使用 Sparkle Ed25519 签名校验。
- 存在连接时暂停检查更新，退出前保存配置。
- 保留 SSH、SFTP、FTP / FTPS、凭据备份与深浅主题功能。

仅支持 Apple Silicon（arm64），macOS 12 或更新版本。

本版本没有 Apple Developer ID 签名及公证。首次安装可能被 Gatekeeper 拦截：将应用拖入「应用程序」，确认来源后在「系统设置 → 隐私与安全性」中允许打开。不要关闭系统整体安全检查。

0.3.0 及以前的版本没有内置 Sparkle，需手动安装本版一次。
