# Proposal

## Why

文件面板目前只支持单选下载：每次只能选中一个文件或目录，且单文件下载必须逐个经过保存对话框确认。用户需要下载同一目录下的多个文件、多个目录或文件与目录混合内容时，只能反复点击、反复确认，既无法一次性查看整体进度，也无法统一暂停、继续或停止。

## What Changes

- 文件列表支持多选：每行提供复选框（默认不占位，悬浮、聚焦或已选中时显示并替代文件类型图标）；`Cmd/Ctrl + 单击` 切换单项，`Shift + 单击` 选择连续区间；工具栏提供全选 / 取消全选并显示已选数量。虚拟列表下全选作用于当前可见（未被「隐藏文件」过滤）的全部条目。
- 下载入口改为对当前选择生效：
  - 只选中一个文件时保持现有行为，弹出保存对话框确认目标文件名。
  - 只选中一个目录时保持现有行为，选择本地父目录后按目录名创建。
  - 选中多个条目（文件、目录可混合）时只选择一次本地目标文件夹，所有顶层条目按原名称放入该文件夹，作为**一个**下载任务执行。
- 批量下载复用现有传输能力：传输前扫描并固定文件总数与总字节，沿用同名冲突的「跳过所有同名文件并继续 / 停止传输」策略、暂停 / 继续 / 停止、失败清理、结束汇总与多任务独立性；任务标题使用「首项名称 等 N 项」。
- 符号链接不可下载：符号链接行的复选框禁用，全选与区间选择自动排除；若选择中只含符号链接，下载入口禁用。
- 单次批量下载所有选中条目的条目总数仍受 20000 上限约束；任一顶层名称不是单一文件名或解析后落在目标根目录之外时，下载在写入前中止。
- 选择在目录切换、刷新后清空；重命名与删除仍只对单选生效，多选时禁用并提示。
- 新增批量下载 IPC 入口；现有单条目下载 IPC 保留，供单选路径使用。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `remote-file-transfer`: 下载入口由「单选后逐个确认目标」扩展为「多选后一次选择目标文件夹、作为单个批量任务下载」，并补充多选交互、符号链接排除、目标目录共享与选择生命周期等要求。

## Impact

- 代码：`src/FileBrowser.tsx`（多选状态、行复选框、修饰键与区间选择、全选、下载入口分流）、`src/styles.css`（选中态与复选框样式）、`electron/preload.cjs` 与 `src/types.ts`（新增批量下载 IPC 与类型）、`electron/main.cjs`（批量下载处理、多顶层条目下载计划与目标根目录校验）。
- 测试：`tests/ssh.integration.test.cjs` 增加多文件、文件夹混合、同名冲突、暂停/停止与数量上限的批量下载用例；`scripts/smoke.cjs` 补充选择与下载按钮状态断言。
- 文档：`README.md` 与 `src/App.tsx` 帮助文本说明多选方式与批量下载目标目录规则。
- 兼容性：单选下载、双击下载、目录结构、文件名校验与 20000 条目上限保持现有语义；重命名、删除等既有单条目操作行为不变。
